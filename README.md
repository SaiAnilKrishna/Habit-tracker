# FocusForge - Habit Tracker (Java)

## Features
- Add daily habits
- Track progress with streaks
- Visual progress bar
- Persistent storage using file handling

## Technologies
- Java
- File I/O
- OOP concepts

## How to Run

1. Compile:
javac FocusForge.java Habit.java

2. Run:
java FocusForge

## Description
FocusForge is a CLI-based habit tracker that allows users to track daily habits and maintain streaks with persistent data storage.
